## 1. 少ない手間で出品する（01_spec.md 4章 B-② への付け足し）

**問い：** 畑仕事の合間の数分で出品を終えるには、何を省けるか？（何回のタップで終わるか数えてみる）

### 手間がかかりそうな項目

01_spec.md の出品項目（10個）のうち、次の2つが特に手間だと考えた。

- **単価**：相場・送料・選別・梱包を考える必要がある。規格外品や余剰品は、通常品と別の値段を考える必要がある。
- **最低注文量・注文単位**：飲食店が扱いやすい量と、坂田さんが出荷しやすい量は違う。小さい飲食店は、量が多すぎると困る。

### 単価（再検討中）

- 最初は「AIが相場などを考慮した価格を提案し、最終判断は坂田さんが行う」案を考えた。
- AIが何を根拠に提案するか（AIは今週の相場を知らない、AIに渡せる情報は限られる）を考えた結果、いったん保留にして考え直す。
- 結論：単価は省略せず、AIの提案も使わない。01_spec.md のとおり、坂田さんが自分で入力する。

### 最低注文量・注文単位：「探しています」を参考にする

決めたこと：

- 最低注文量の入力欄の下に「『探しています』を確認してみる」を表示する。
- 押すと、飲食店の「探しています」の一覧を表示する。一覧は、希望数量が少ない飲食店から順に並べる。
- 一覧は、最初から次の2つで絞り込んだ状態で表示する（坂田さんが絞り込みの操作をしなくてよい）。
  - 生産者プロフィールの「畑の地域」に近い地域の「探しています」
  - 出品画面で入力済みの「食材名」と同じ食材の「探しています」

そう決めた理由：

- 「探しています」は、坂田さんがまだ出品していなくても見られる。購入希望は出品後にしか届かないので、最初の1回目の手がかりになるのは「探しています」のほう。
- お店が求める量に合わせた出品ができ、三上さんの廃棄（量が多すぎる）を減らすことにもつながる。
- すでに入力済みの情報で絞り込むので、地域を選ぶ操作（約3タップ）が不要になる。

使う情報：

- 「探しています」は、地域と条件だけを生産者に公開する。店名・住所は見せない（01_spec.md 4章 A-④、補足）。
- 検索しただけで公開していない仕入れ条件は使わない（不変条件4：他人の情報は見えない）。

希望数量が少ない順に並べる理由：

- 少ない量に合わせて最低注文量を決めると、より多くの飲食店（小さいお店も）に野菜を届けられる。坂田さんにとっては、繋がれる店が増える。

### 最低注文量：出荷の負担を件数で見せる

少ない順に並べると、坂田さんが一番上の小さい量につられて、出荷が大変な量まで最低注文量を下げてしまうおそれがある。小分け・梱包・発送は1件ごとに発生するので、負担は「少量の注文の件数」で決まる。そこで、次のようにする。

- 最低注文量を入力したとき、その場で「最大◯件の発送になる可能性があります」と表示する。
  - 最大件数 ＝ 販売可能総量 ÷ 最低注文量（アプリが計算する。AI は使わない）
  - 例：賀茂茄子30kg、最低注文量1kg → 最大30件。3kg → 最大10件。
- 坂田さんは、あらかじめ「1回の出荷で何件までなら対応できるか」（例：10件）を設定しておく。
- 最大件数がその基準を超えたら「負担が大きい」と表示する（例：大・中・小の表示や、数字を赤くする）。

| 最低注文量 | 最大件数 | 坂田さんの基準 | 判定 |
|---|---|---|---|
| 1kg | 30件 | 10件 | 負担が大きい |
| 2kg | 15件 | 10件 | 負担が大きい |
| 3kg | 10件 | 10件 | 大丈夫 |
| 5kg | 6件 | 10件 | 大丈夫 |

考え直した点：

- 最初は境目を「最大件数の〇割」にする案を考えた。しかし、ある数とその数の一部を比べると必ず「大」になるため、境目は表示する数字とは別の、坂田さん自身の基準（対応できる件数）にした。

「1回の出荷で何件まで」の設定：

- 基本は、生産者プロフィールの作成時に1回設定する（出品のたびに入力しなくてよい）。
- いつでも変更できるようにする。忙しい時期など、状況が変わったときに反映できる。
- 出品画面の最大件数の表示のそばに、今の基準と「件数を変更する」を表示する。坂田さんは、プロフィール画面に移動しなくても、出品しているその場で基準を思い出し、直せる。

```
最低注文量  [ 1 ] kg

  最大30件の発送になる可能性があります
  あなたの基準：1回の出荷で10件まで → 負担：大

  [件数を変更する]
```

「負担が大きい」ときの扱い：

- 注文の受付は止めない。受け付けるかどうかは坂田さんが判断する（「今週は多めに出す」という選択もできるようにするため）。
- 「負担が大きい」のまま「出品する」を押したときだけ、そのまま出品せず、一度注意書きを表示する。基準の範囲内なら、注意書きは出さずにそのまま出品する。
- 出品後も、届いた注文は注文ごとに承認・見送りできる（01_spec.md 4章 B-⑤）。

```
（最低注文量 1kg、最大30件、基準10件 → 負担：大 のまま）

[出品する] を押す
   ↓
┌───────────────────────────────┐
│ 最大30件の発送になる可能性があります。│
│ あなたの基準（10件）を超えています。  │
│ このまま出品しますか？               │
│                                     │
│  [最低注文量を見直す] [このまま出品する]│
└───────────────────────────────┘
```

まだ考えること：

- 出品画面で「件数を変更する」を押したとき、プロフィールの基準も変わるのか、その出品だけ変わるのか
- 一覧を見たあと、出品画面にどう戻るか。入力途中の内容は消えないか
- 該当する「探しています」が0件のとき、何を表示するか
- 「代替野菜も可」「種類を問わない」の「探しています」は、食材名の絞り込みでどう扱うか
